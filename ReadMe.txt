================================================
server сервера
================================================

Сначала запустите PowerShell, чтобы открыть порты. Это позволит клиентам подключаться.

Пароль сервера = RemoteX1#

Отправьте в службу поддержки идентификатор машины, и они предоставят вам лицензию:
t.me/privatetoolsmarketsupport

Вы можете выбрать между настольной версией и браузером для панели управления.
Мы рекомендуем браузер, он намного быстрее.

Затем откройте браузер и перейдите по адресу localhost:80.
Там вы найдете панель управления.
